# App Padel — Prototype

Prototipo visual mobile-first para validar la experiencia central del producto:

> Crear un partido, compartirlo y conseguir al jugador que falta.

## Qué incluye

- Inicio con el próximo partido y su estado.
- Detalle visual de jugadores confirmados y lugar libre.
- Flujo de creación de partido.
- Vista de partidos abiertos cercanos.
- Actividad y nivel habitual simplificados.
- Navegación e interacciones de demostración.

## Ejecutar

Es un sitio estático. Abrí `index.html` con Live Server o cualquier servidor HTTP local.

```bash
npx serve .
```

No incluye backend, autenticación, persistencia, reservas ni matchmaking real. La rama está enfocada en diseño, jerarquía de producto y recorrido de usuario.
